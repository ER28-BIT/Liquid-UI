# Changelog

## 0.3.0 — Atmospheric foundation

- Adds light/dark atmosphere, three glass tiers, refraction, blur & glow tokens.
- Adds a display type token & persona-informed design strategy centered on
  participation, accountable decisions & shared value.
- Adds dialog, tab & toast presentation while retaining the token-only default
  export and dependency-free CSS package.
- Replaces inactive showcase controls with working links, dialogs, keyboard tabs,
  display settings, local form feedback & dismissible confirmation previews.
- Restores all seven governed states to the showcase; labels product data as
  illustrative & distinguishes evidence readiness from payment authorization.
- Adds manual/OS opaque modes, no-backdrop-filter fallback & forced-color focus
  treatment. Darkens light-theme muted text for improved body-text contrast.
- Preserves existing token names and pinned-snapshot consumption.

This private version is not a registry publication or downstream product update.
